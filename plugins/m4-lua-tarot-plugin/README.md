# M4 Tarot

墨水屏塔罗牌插件首版。先使用 22 张大阿尔卡那，把完整闭环做通，再考虑扩展 56 张小阿尔卡那。

## 功能
- 今日一牌：同一天固定一张，约 20% 概率逆位。
- 随机一牌：随机抽牌，约 35% 概率逆位。
- 三牌阵：过去 / 现在 / 未来，不重复抽取。
- 点击三牌阵中的牌查看大图、正逆位和关键词。
- 22 张牌库浏览。
- 最近一次结果保存到插件 appdata。
- 仅作为娱乐和自我反思，不替代现实中的专业判断。

## 墨水屏设计
- 卡面 140×240、1-bit BMP；三张横排总宽 450 px，适配 480×800。
- 牌背、22 张牌面、程序图标全部为 1-bit BMP。
- `tools/tarot-sprite-sheet.png` 在一张大图里包含程序图标、牌背和 22 张实际游戏牌面。
- 只在界面可见状态变化时触发新画面。

## 操作
主页：Confirm=随机一牌，Up=今日一牌，Down=三牌阵，Right=牌库，也可直接触控。
三牌阵：触摸任意牌进入详情；详情可上一张/下一张。
