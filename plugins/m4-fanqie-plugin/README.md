# Murphy M4 番茄小说 plugin

番茄小说内容提供器插件，支持书源目录、文件行源目录、章节缓存、原生阅读器接管与历史进度恢复。

这是持续 USB 调试链路上的最新插件导出：源自固件仓库分支
`luna/m4-plugin-home-ui`，版本 `0.2.11`（versionCode 22）。目录会优先读取本地缓存；分类书单和正文优先使用宿主 JSON 投影。目录截断和旧路径均原地释放，正文优先 `file_out` 直写 SD：网络 JSON 和正文不会复制到 Lua 堆，写入完成后原生阅读器直接打开缓存文件；旧宿主自动回退兼容路径。
插件包只包含 `manifest.json` 与清单列出的 Lua 文件；不会携带真实书源响应、账号数据或缓存书籍内容。

## 安装

将 `.m4x` 文件通过持续 USB 调试会话或设备文件传输入口放入应用安装目录，再由 M4 宿主安装。宿主固件与插件分开维护。
