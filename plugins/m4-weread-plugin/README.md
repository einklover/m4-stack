# Murphy M4 WeRead plugin

微信读书内容提供器插件，支持扫码登录、书架/目录、章节缓存、原生阅读器接管与历史进度恢复。

这是持续 USB 调试链路上的最新插件导出：源自固件仓库分支
`luna/m4-plugin-home-ui`，版本 `0.6.7`（versionCode 25）。书架/目录优先使用宿主投影与 SD 卡缓存；章节分片在解码后立即释放，避免多份正文/凭证同时占用 Lua 堆；只有缓存不存在或损坏时才联网。
插件包只包含 `manifest.json` 与清单列出的 Lua 文件；不会携带账号 Cookie、二维码、真实章节抓取或本机路径。

## 安装

将 `.m4x` 文件通过持续 USB 调试会话或设备文件传输入口放入应用安装目录，再由 M4 宿主安装。宿主固件与插件分开维护。

## 发布状态

协议实现和第三方引用仍需在公开发布前完成许可证与服务条款复核；当前导出不声明未经核验的开源许可证。
